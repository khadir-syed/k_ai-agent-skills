Agents

Skills that work together

A skill does one job. An agent does a few jobs in a row to finish something bigger — like a cook who follows three recipe cards, one after another, to make a whole meal.

Every agent here comes as a pair that does the same work. The controlled one checks with you after every step. The autonomous one does the routine steps alone, but still asks before it saves or sends anything — or, for the Software team, stops itself after a set number of tries. The only difference is how often a person checks in.

Product team Do the whole job with me Takes a one-line feature request through all 3 skill jobs: find what's missing, write a short launch plan, run the launch checks. See the two versions side by side, with real runs. Content team Get a post ready to publish The same 3 steps for a blog post: find what's missing from the brief, write the draft, run the publish checks. See the two versions side by side, with real runs. Software team Find and fix a bug Finds the bug, fixes it, and checks the fix worked. One version asks before every change; the other keeps trying on its own until the program's own tests pass, or it hits a limit. See both, with real runs.

Social media has its three skills but no agent here — that one is left for you to try. Follow the same pattern as the agents above: the skills in a row, and choose how often it checks with you.
