In short

AI is a computer helper you can talk to.

This site shows how to give it good rules.

Think of a kitchen.

A recipe card says how to make one dish. That is a skill.

A cook uses a few cards to make a meal. That is an agent.

A waiter takes your order to the right cook. That is an orchestrator.

AI skills, explained

This is a free library of instructions for AI helpers — the kind you can chat with, like Claude, OpenAI's Codex or GitHub Copilot. Each instruction file teaches the AI to do one kind of work the same careful way every time.

The library has three parts, each building on the one before. Think of a restaurant kitchen:

  • Skills are recipe cards: one job, done the same way every time.
  • Agents are cooks who follow a few recipe cards in a row to make a whole meal.
  • Orchestrators are the head waiter, who hears your order and sends it to the right cook.

Every page shows real runs. A run is one real chat with an AI: what we asked it, and exactly what it answered (only personal details are ever taken out). No coding needed.

How the three parts fit

Part 1 Skills Three jobs — find what's missing, write a first draft, check it's ready — each for four teams: Product, Content, Social media and Software. Part 2 Agents Skills that work together. For the Product, Content and Software teams, see an agent that asks you after every step next to one that asks far less. Part 3 Orchestrators You describe your problem in your own words; the orchestrator works out which agent it belongs to — a bug, a feature launch or a blog post — and hands it over. It never does the work itself.

Want to use these skills yourself, in Claude Code, Codex or GitHub Copilot CLI? Everything is free on GitHub (the website where the files live), with a script that sets them up for you.
