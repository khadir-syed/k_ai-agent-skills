Orchestrators · Request Router

Send it to the right agent

Same request, two orchestrators: one checks its choice with you, one doesn't — but says so first

In short

A restaurant has many cooks.

A waiter listens to you and picks the right cook.

One waiter asks you, "Is this OK?"

The other waiter does not ask, but tells you first.

If they can't tell what you mean, both ask.

Think of the head waiter in a restaurant. You say what you'd like in your own words, and they send the order to the right cook. The head waiter never cooks — and they don't get to tell the cook to skip the safety rules either.

An orchestrator is that head waiter for AI agents. You describe your problem; it works out whether it's a bug, a feature launch or a blog post, and hands it to that team's agent. Its only job is that one choice. The controlled one stops to check its choice with you. The autonomous one doesn't — so for a bug, which it hands to a program that never asks anything, it must first warn you out loud.

In plain words: both got the same broken program as the bug-fixing agents: a test checks that a spreadsheet file (CSV) starts with Name,Email,ID, and it fails because the program forgot the ID column.

One request, two ways

Controlled stops once, to check its choice. After you say yes, it steps aside: from then on it simply is the bug-fixing agent, and that agent still asks at each of its own stops.

Autonomous never stops to ask. For a bug, it first says plainly that nothing more will be asked, then runs the program that fixes the bug on its own, checks what the program changed, and tells you the result.

Both have one place where they must stop: when a request could belong to two agents — "the export isn't working right for next week's launch" could be a bug or an unfinished launch — they're told to ask which you mean instead of guessing. See it happen below.

The lesson: whoever hands out the work can't switch off the checks that come after it. And when something is about to run without asking you, you should be told before it starts, not after.

What we gave both orchestrators

The same small broken program, in a folder of its own, with the agents they can hand work to: export.py builds the column names, and test_export.py checks them.

export.py
HEADER_FIELDS = ["Name", "Email"]

def build_csv_header():
    return ",".join(HEADER_FIELDS)

test_export.py
import unittest
from export import build_csv_header

class TestExport(unittest.TestCase):
    def test_csv_header(self):
        self.assertEqual(build_csv_header(), "Name,Email,ID")

if __name__ == "__main__":
    unittest.main()

      When it can't tell

      Say you tell the head waiter: "the soup isn't right, and the party is tonight." Is that a complaint for the cook, or a change to the party menu? A good head waiter doesn't guess. They ask.

      We gave both orchestrators a request like that. Everything else was the same as above: the same folder, with the broken program in it, and both agents the request could go to. So guessing "it's the bug" would have been easy.
